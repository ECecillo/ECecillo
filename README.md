<h1 align="center">Hi, I'm Enzo 👋</h1>

Backend software engineer, mostly in **Go**. From 2024 to 2026 I worked at
[Batch](https://batch.com) on the messaging platform: the services that route
and deliver push, email and SMS at scale. Before that I spent two years
(2022–2024) as an apprentice building a large-scale web application at
[Kestio](https://www.kestio.com/). I hold a master's degree in Web Technology
and Network Communication from the [University of Lyon 1](https://www.univ-lyon1.fr/).

### 🔭 Featured projects

- **[tomeshift](https://github.com/ECecillo/tomeshift)**: translates EPUB books
  from English to French while preserving their structure. Cheap MT drafts, a
  translation memory, LLM calls only where a quality estimator asks for them,
  budget guards, resumable runs.
- **[gotun](https://github.com/ECecillo/gotun)**: a userspace UTUN tunnel for
  macOS. Kernel control sockets, ioctl interface setup, TCP/UDP forwarding with
  connection tracking.
- **[lib.go.sound](https://github.com/ECecillo/lib.go.sound)**: digital sound
  generation library. Golden-file, fuzz and benchmark testing gated in CI.

- 📝 I write about what I learn on [dev.to/ececillo](https://dev.to/ececillo)
- 💬 Ask me about **Go, distributed systems, and message delivery pipelines**
